# Task 1.1: Backend Server Configuration

## Objective
Configure the backend server for test mode operation by creating test-specific configuration and ensuring the server can start/stop cleanly for test isolation.

## Scope
- Create test-specific `appsettings.Test.json` configuration
- Ensure server can start/stop cleanly for test isolation using `dotnet run` with `--urls=http://localhost:8012` and `environment=Test`
- Document the test start command in the top level README.md

## Requirements

### Test Configuration File
Create `src/backend/SQLisHard/appsettings.Test.json` with:
- Test-specific database connections
- Test environment settings
- Appropriate logging levels for testing
- Test-specific timeouts and configurations

### Server Startup Configuration
Configure server to start in test mode using:
- `dotnet run` command with `--urls=http://localhost:8012`
- `environment=Test` environment variable
- Clean startup and shutdown procedures
- Proper port binding for test isolation

### Documentation
Update the top-level `README.md` to include:
- Test server startup command
- Environment configuration details
- Test mode explanation
- Quick reference for developers

## Implementation Steps

1. **Create Test Configuration File**
   ```json
   // appsettings.Test.json
   {
     "ConnectionStrings": {
       "CoreDatabase": "Server=localhost;Database=SQLisHard_Core_Test;Trusted_Connection=true;",
       "ExerciseDatabase": "Server=localhost;Database=SQLisHard_Exercises_Test;Trusted_Connection=true;"
     },
     "Logging": {
       "LogLevel": {
         "Default": "Information",
         "Microsoft": "Warning",
         "Microsoft.Hosting.Lifetime": "Information"
       }
     },
     "TestSettings": {
       "Timeout": 30000,
       "EnableDetailedLogging": true
     }
   }
   ```

2. **Verify Server Startup**
   ```bash
   cd src/backend/SQLisHard
   dotnet run --urls=http://localhost:8012 --environment=Test
   ```
   - Ensure server starts successfully
   - Verify test configuration is loaded
   - Confirm server responds on port 8012

3. **Update README.md**
   ```markdown
   ## Testing
   
   ### Starting the Test Server
   ```bash
   cd src/backend/SQLisHard
   dotnet run --urls=http://localhost:8012 --environment=Test
   ```
   
   The test server will start on port 8012 with test-specific configuration.
   ```
