# Task 1.2: Playwright Project Setup

## Objective
Set up the Playwright project infrastructure with TypeScript, including npm project initialization, dependencies, and basic project structure.

## Scope
- Create `/src/e2e-tests/` directory structure
- Initialize npm project with TypeScript
- Install Playwright dependencies
- Configure Playwright and TypeScript
- Set up ESLint with TypeScript settings
- Create basic project structure

## Requirements

### Directory Structure
Create the following structure:
```
/src/e2e-tests/
├── package.json
├── playwright.config.ts
├── tsconfig.json
├── .eslintrc.js
├── tests/
│   ├── basic-query-execution.spec.ts
│   ├── exercise-interaction.spec.ts
│   └── helpers/
│       ├── page-objects/
│       │   └── exercise-page.ts
│       └── test-utils.ts
└── README.md
```

### Dependencies
Install the following packages:
- `@playwright/test` - Playwright testing framework
- `typescript` - TypeScript compiler
- `@typescript-eslint/eslint-plugin` - ESLint TypeScript plugin
- `@typescript-eslint/parser` - TypeScript parser for ESLint
- `eslint` - ESLint linter

### Configuration Files
- `playwright.config.ts` - Configured for Chrome-only testing
- `tsconfig.json` - TypeScript configuration
- `.eslintrc.js` - ESLint configuration with TypeScript settings

## Implementation Steps

1. **Initialize npm Project**
   ```bash
   cd src/e2e-tests
   npm init -y
   ```

2. **Install Dependencies**
   ```bash
   npm install -D @playwright/test typescript
   npm install -D @typescript-eslint/eslint-plugin @typescript-eslint/parser eslint
   npx playwright install chrome
   ```

3. **Create Configuration Files**
   - Create `playwright.config.ts` with Chrome-only configuration
   - Create `tsconfig.json` with appropriate TypeScript settings
   - Create `.eslintrc.js` with TypeScript ESLint rules

4. **Create Directory Structure**
   - Create `tests/` directory
   - Create `tests/helpers/` and `tests/helpers/page-objects/` directories
   - Create placeholder files for tests and helpers

5. **Create README.md**
   - Document project setup
   - Include npm scripts
   - Add basic usage instructions
