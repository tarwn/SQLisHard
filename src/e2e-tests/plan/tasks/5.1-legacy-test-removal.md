# Task 5.1: Legacy Test Removal

## Objective
Remove the old .Net integration test project and clean up all legacy test code, ensuring the new Playwright tests are fully functional before removal.

## Scope
- Remove old .Net integration test project
- Update solution file to remove old test references
- Clean up unused dependencies
- Update documentation
- Ensure no breaking changes to main application

## Requirements

### Legacy Test Project Removal
Remove the following directory and files:
- `src/backend/SQLisHard.IntegrationTests/` (entire directory)
- All C# SpecFlow test files
- Selenium WebDriver dependencies
- SpecFlow configuration files

### Solution File Updates
Update `src/backend/SQLisHard.sln` to:
- Remove references to `SQLisHard.IntegrationTests` project
- Clean up any unused project references
- Ensure solution builds correctly

### Dependency Cleanup
Remove unused NuGet packages:
- SpecFlow packages
- Selenium WebDriver packages
- Test-related packages that are no longer needed

### Documentation Updates
- Update README files
- Remove references to old test system
- Update development setup instructions

## Implementation Steps

1. **Verify New Tests Are Complete**
   ```bash
   cd src/e2e-tests
   npm run test
   ```
   - Ensure all new tests pass
   - Verify test coverage is complete
   - Confirm no functionality is lost

2. **Remove Legacy Test Project**
   ```bash
   cd src/backend
   rm -rf SQLisHard.IntegrationTests/
   ```

3. **Update Solution File**
   ```bash
   # Remove project reference from solution
   dotnet sln remove SQLisHard.IntegrationTests/SQLisHard.IntegrationTests.csproj
   ```

4. **Clean Up Dependencies**
   ```bash
   # Remove unused NuGet packages from main project
   dotnet remove package SpecFlow
   dotnet remove package Selenium.WebDriver
   # ... remove other unused packages
   ```

5. **Update Documentation**
   - Update main README.md
   - Update development setup instructions
   - Remove old test documentation
