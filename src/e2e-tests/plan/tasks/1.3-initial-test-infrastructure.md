# Task 1.3: Initial Test Infrastructure

## Objective
Create the foundational test infrastructure including base page object class, exercise page object, test utilities, and test configuration management.

## Scope
- Create base page object class (`base-page.ts`)
- Create `exercise-page.ts` page object (migrate from C# `LessonPage.cs`)
- Create test utilities for common operations
- Set up test configuration management

## Requirements

### Base Page Object
Create `tests/helpers/page-objects/base-page.ts` with:
- Common page object methods and properties
- Navigation utilities
- Wait and timeout handling
- Error handling utilities

### Exercise Page Object
Create `tests/helpers/page-objects/exercise-page.ts` with:
- Migration of C# `LessonPage.cs` functionality
- Query input and execution methods
- Result verification methods
- Exercise selection methods
- Status indicator methods

### Test Utilities
Create `tests/helpers/test-utils.ts` with:
- Common test setup and teardown utilities
- Database connection helpers
- Test data management
- Configuration loading utilities

### Configuration Management
Create `tests/helpers/config.ts` with:
- Test configuration interface
- Environment-specific settings
- Database connection settings
- Test data configuration

## Implementation Steps

1. **Create Base Page Object**
   ```typescript
   // base-page.ts
   export class BasePage {
     constructor(protected page: Page) {}
     
     async navigate(url: string): Promise<void>
     async waitForElement(selector: string): Promise<void>
     async waitForPageLoad(): Promise<void>
     // ... other common methods
   }
   ```

2. **Create Exercise Page Object**
   ```typescript
   // exercise-page.ts
   export class ExercisePage extends BasePage {
     private queryInput = this.page.locator('#queryInput');
     private queryExecutionButton = this.page.locator('#queryExecutionButton');
     private resultsContainer = this.page.locator('#resultsContainer');
     
     async enterQuery(query: string): Promise<void>
     async executeQuery(): Promise<void>
     async expectResultsDisplayed(): Promise<void>
     // ... other exercise-specific methods
   }
   ```

3. **Create Test Utilities**
   ```typescript
   // test-utils.ts
   export class TestUtils {
     static async setupTestDatabase(): Promise<void>
     static async cleanupTestData(): Promise<void>
     static async loadTestConfiguration(): Promise<TestConfig>
     // ... other utility methods
   }
   ```

4. **Create Configuration Management**
   ```typescript
   // config.ts
   export interface TestConfig {
     baseUrl: string;
     firstExerciseQuery: string;
     patternExerciseId: string;
     testDatabase: {
       core: string;
       exercises: string;
     };
   }
   ```
